# v0.2.20.1（2026-11-24）

上游同步：Strata 0.2.20（Control 与三套引擎家族同步 0.1.66），应用版本 0.2.20.1（局域网放行变体）。

## 变更

1. 应用主体换上游 0.2.20 AppImage 解包：`host`、`harness`、`node`。AppImage 内 `engine-bundle` 只有占位，引擎由官方 engine tarball 提供。
2. control 换 **0.1.66**（AppImage 内解包，与官方 `strata-control-0.1.66-linux-x86_64.tar.gz` 校验和一致：94,663,788 B / `5bd662d293ab4dc8b71156daafbb42995bddbb765dbeac48c5fd74165dfb2d0d`）。
3. 引擎换 **0.1.66**（官方 `strata-engine-0.1.66-linux-x86_64-cuda-cuda12.tar.gz` 782,739,940 B / `74980aebedc70fb2cfcd96b3c15874cb3e7e517700ecdf8ed811247a9a577f30`），放 `fnpack/app/engine-bundle/0.1.66-linux-x86_64-cuda-cuda12/`，随包 `engine-component.json` 逐文件校验通过；`sm_75`（RTX 20 系）在支持架构列表内（`sm_60/61/70/75/80/86/89/120`），CUDA 12.9 便携构建。
4. host 重放 0004 局域网放行补丁（`/api/*` 的 Origin 白名单由 `localhost/127.0.0.1/[::1]` 改为按本机名与私网 IPv4 判定），补丁按内容锚点落位，构建时反向校验其余补丁锚点全为 0。
5. 本变体构建走 `scripts/build-lan.sh`（局域网放行变体：只带 0004，其余补丁不重放）。

上游 0.2.18 → 0.2.20 面向使用者的要点：

- **0.2.20**：Qwen3.8-Flash-Next、HY-4 Flash、Inkling 2 Mini 三条 MoE 线统一到 4 层执行计划（GPU 常驻稠干与量化 KV + 热专家进显存 + 冷专家进内存 + SSD 流式），最低支持 4 GiB 显存；32K 以上上下文在中显存卡上自动 `--kv-offload auto`；多卡 `--layer-split auto`（2–4 卡）打通；Unsloth GGUF 与 Strata Quant 全档提速，NVIDIA CUDA（`sm_60`–`sm_121`）13 组专家格式全开，MoE 解码 `1.04x–1.67x`、下投影最高 `2.58x`，INT8 Tensor Core 稠密格式校验/分块预填充 `1.78x–3.26x`。
- **0.2.19**：新增原生 Inkling 2 Mini 支持（独立 shape 引擎），三档量化包 SQ-10 / SQ-15 / SQ-20（SQ-20 无损），自带视觉与内置投机解码。
- **0.2.18**：新增原生腾讯 HY4-Flash 支持（独立 shape 引擎），SQ-64 / SQ-96 / SQ-128 三档量化包，内置 DFly2 投机解码与原生视觉。
- 升级方式不变：已有模型、对话与设置不受影响。Control 与引擎继续同号（0.1.66）。

## 安装

应用中心「手动安装」选择该 fpk。已装旧版时应用中心会先卸载再装（`/vol1/@appdata/strata` 数据默认保留，模型与设置不丢）。安装后首次启动会把随包引擎搬进引擎库，属预期行为。独立部署的生产引擎切换由基础设施侧单独执行，不依赖本包。
