# v0.2.20.2（2026-11-24）

应用版本 0.2.20.2（局域网放行变体），仅修安装回调，应用主体与引擎内容与 0.2.20.1 完全一致。

## 本版修复

**安装/升级回调不再因首启失败而整包回滚。**

- 现象：在应用中心升级到 0.2.20.1 时弹出「无法更新 strata / 执行脚本出错且原因未知」，版本停在上一个版本。
- 原因：`cmd/install_callback` 末尾以 `main start || exit 1` 结束。升级流程会执行该回调，只要首启失败（本次是 `service_port` 8791 已被同一台机器上的其他程序占用，`[strata] Port 8791 is already in use …`），回调返回非 0，应用中心判定为安装回调异常并整包回滚，界面上只能看到「执行脚本出错且原因未知」。
- 修法：回调改为「启动成功记日志；启动失败也只记一条日志（含当前占用该端口的进程），**两种结果都正常退出**」。安装与升级不再被首启结果影响。
- 附带：首启失败时日志会写明端口占用者（`ss -lntp` 匹配结果），不必再翻应用中心日志猜原因。

## 环境说明（端口）

本应用宿主绑定 `manifest` 的 `service_port`（8791），端口直达、不走统一网关。若 8791 已交给别的程序（例如 Strata 面板类应用），本应用安装会正常完成、宿主不会被拉起；空闲后可在应用中心点启动，或改用其他端口。

## 冒烟（隔离实例，端口 8799，不加载模型、不占 GPU）

- `scripts/smoke.sh`：套件自带解释器 `import serve.server` ✓；`serve/server.py` 子进程起来、`/health` 200 ✓；补丁新增代码 import 对齐静态检查 ✓；补丁守卫 0004 局域网 Origin ✓。
- 0005 角色→设备 / 0005 卡名日志 / 0010 就绪外部凭据 三项守卫失败属本变体设计（局域网放行变体只带 0004），非回归。
- 回调单测：用会返回 1 的 `main` 桩（打印 `Port 8791 is already in use`）跑 `install_callback`，退出码 **0**，日志记下端口占用者。
