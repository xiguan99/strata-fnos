# v0.2.13.2（2026-11-12）

上游同步：Strata 0.2.13（control 0.1.59.1 + CUDA 引擎 0.1.59），应用版本 0.2.13.2（局域网放行变体）。

## 变更

1. 应用主体换上游 0.2.13 AppImage 解包：`host`（15M）、`harness`（288M，BUNDLE.json 仍为 deepseek-harness 0.2.1-alpha.3 / node v24.12.0）、`node`（116M）。AppImage 内 `engine-bundle` 只有 `.gitignore`，引擎改由官方 engine tarball 提供。
2. control 换 **0.1.59.1**（`strata-control-0.1.59.1-linux-x86_64.tar.gz`；0.2.13.1 起修 Intel Arc 的版本）。与 AppImage 内 0.1.59 的差异只有 `python/lib/libpython3.12.so`（AppImage 为实体文件、tarball 为指向 `libpython3.12.so.1.0` 的符号链接，内容等价）。
3. 引擎换 **0.1.59**（`strata-engine-0.1.59-linux-x86_64-cuda-cuda12.tar.gz`，build_id `712fec6b4297+cuda12.9`，archs 含 sm_75，min_driver 575.51），放 `fnpack/app/engine-bundle/0.1.59-linux-x86_64-cuda-cuda12/`。
4. host 重放 0004 局域网放行：`server/index.mjs` 顶部 import 加 `hostname as osHostname`，插入 `localHostNames`/`privateV4`/`isLocalOrigin()`，把 `/api/*` 的 Origin 白名单从 `['localhost','127.0.0.1','[::1]']` 换成 `isLocalOrigin(origin.hostname)`。其余补丁（0001 本地 MTP 复用、0003 GGUF 宽松校验、0005/0007/0008/0009/0010 等）本变体不带。
5. 本版本宿主 `server/index.mjs` 另有一处上游改动（#4397）：坏 Host/请求目标一律 400（`const url = requestUrl(req); if (!url) return badRequest(res);`），不影响补丁位置。

上游 0.2.13 相对 0.2.12 的要点（面向使用者）：DFlash2 按卡设默认（+2.8%~5.2%）、Linux 专家库重新走文件缓存加载（#5327 / PR #5531）、Intel Arc 输出确定性、启动器原先写的设置下沉为引擎默认（裸引擎启动即与 app 一致）、fit 标签统一为「fits / may run slower」、移除 8 个已结束实验的开关（`STRATA_METAL_ROUTE`/`STRATA_METAL_PARTIAL`/`STRATA_METAL_WPF_MIB`/`STRATA_MMVQ_PF`/`STRATA_MMVQ_SG`/`STRATA_GR_Q32_PL`/`STRATA_DF2_GATE`/`STRATA_DF2_ROW_MS`）、Qwen4 形状引擎铺垫（`strata-q4-<shape>` + `strata --geometry`）、Linux 数据目录可放外置盘（`/run/media`、`/media`、`/mnt`）。
