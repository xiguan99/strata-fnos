# v0.2.16.2（2026-11-19）

上游同步：Strata 0.2.16（control 0.1.62 + CUDA 引擎 0.1.62，Control 与引擎从本版起同号），应用版本 0.2.16.2（局域网放行变体）。

## 变更

1. 应用主体换上游 0.2.16 AppImage 解包：`host`（15M）、`harness`（288M，BUNDLE.json 仍为 deepseek-harness 0.2.1-alpha.3 / node v24.12.0，builtAt 2026-11-17）、`node`（116M）。AppImage 内 `engine-bundle` 只有 `.gitignore`，引擎改由官方 engine tarball 提供。
2. control 换 **0.1.62**（AppImage 内解包；与官方 `strata-control-0.1.62-linux-x86_64.tar.gz` 的差异只有 `BUNDLE.json` 与 AppImage 多带的 `python/lib/python3.12/ensurepip/_bundled`，功能等价）。
3. 引擎换 **0.1.62**（`strata-engine-0.1.62-linux-x86_64-cuda-cuda12.tar.gz`，build_id `18526b879231+cuda12.9`，archs 含 sm_75，min_driver 575.51，`strata` 本体 375,068,408 B），放 `fnpack/app/engine-bundle/0.1.62-linux-x86_64-cuda-cuda12/`。
4. host 重放 0004 局域网放行：`server/index.mjs` 顶部 import 加 `hostname as osHostname`，插入 `localHostNames`/`privateV4`/`isLocalOrigin()`，把 `/api/*` 的 Origin 白名单从 `['localhost','127.0.0.1','[::1]']` 换成 `isLocalOrigin(origin.hostname)`。其余补丁（0001 本地 MTP 复用、0003 GGUF 宽松校验、0005/0007/0008/0009/0010 等）本变体不带。0.2.16 的 `index.mjs` 在 `createServer` 顶部新增了 `const url = requestUrl(req);` 一行，补丁第二块锚点随之整体下移（重放时按内容手工落位，判据不变）。

上游 0.2.16 相对 0.2.15 的要点（面向使用者）：**引擎代码自研化**——NVIDIA/AMD/Arc/Mac 引擎的矩阵核全部换成 Strata 自己的代码，不再依赖 ggml/llama.cpp，官方 10 条测试提示词在各卡与 0.2.15 逐字一致；图片阅读组件同为自研（NVIDIA 侧从 53,864,888 B 减到 807,976 B）。老 N 卡长提示词提速：Tesla V100 26,000 token 从 17,464 ms（0.1.58 基线）到 15,068 ms；RTX 2080 Ti 26,000 token 相对 0.1.58 的速度比从 0.885（0.2.15）到 1.088。Ubuntu 内存杀手（systemd-oomd）打断模型加载的问题缓解（官方口径为减少、非根除）。聊天界面显示模型动作（Thinking…/Calling read…），工具调用失败不再终止回合（官方 live check 20/20）。Mac M1–M4 的 UD-Q4_K_XL 在 0.2.15 只算 1/4 列的问题已修。Control 与引擎从本版起同号 0.1.62（没有 0.1.61 引擎）。上游仓库顶层目录重构为 engine/、app/、terminal/、docs/、tools/（不影响本包）。

- 解包 `dist/strata_v0.2.16.2_x86.fpk` → `app.tgz` → 应用树；`TRIM_APPDEST=… TRIM_PKGVAR=… TRIM_SERVICE_PORT=8799 bash payload/cmd/main start` 启动成功（`0.0.0.0:8799`），info.log 记录 `strata host 启动成功 PID=1722539` 与 `bundled engine 0.1.62-linux-x86_64-cuda-cuda12: installed`。
