# v0.2.17.0（2026-11-20）

上游同步：Strata 0.2.17（control 0.1.63 + CUDA 引擎 0.1.63，Control 与引擎同号），应用版本 0.2.17.0（局域网放行变体）。

## 变更

1. 应用主体换上游 0.2.17 AppImage 解包：`host`（15M）、`harness`（288M，BUNDLE.json 仍为 deepseek-harness 0.2.1-alpha.3 / node v24.12.0）、`node`（116M）。AppImage 内 `engine-bundle` 只有占位，引擎由官方 engine tarball 提供。
2. control 换 **0.1.63**（AppImage 内解包，BUNDLE.json version 0.1.63 / python 3.12.15；与官方 `strata-control-0.1.63-linux-x86_64.tar.gz` 校验和一致）。
3. 引擎换 **0.1.63**（`strata-engine-0.1.63-linux-x86_64-cuda-cuda12.tar.gz` 768,056,577 B），放 `fnpack/app/engine-bundle/0.1.63-linux-x86_64-cuda-cuda12/`。三件资产 sha256 全部对过官方 `SHA256SUMS.txt`。
4. host 重放 0004 局域网放行：`server/index.mjs` 顶部 import 加 `hostname as osHostname`，插入 `localHostNames`/`privateV4`/`isLocalOrigin()`，把 `/api/*` 的 Origin 白名单从 `['localhost','127.0.0.1','[::1]']` 换成 `isLocalOrigin(origin.hostname)`。其余补丁（0001 本地 MTP 复用、0003 GGUF 宽松校验、0005/0007/0008/0009/0010 等）本变体不带。0.2.17 的 `index.mjs` 结构有重构（`createServer` 顶部的 `const url = requestUrl(req);` 与 0.2.16 位置相同），补丁按内容锚点落位，判据不变（`isLocalOrigin` 命中 2 处）。
5. 本变体构建走 `scripts/build-lan.sh`（[0/3] 变体校验：除 0004 外五处补丁锚点必须全 0）。注意：上游 0.2.17 重构把 0005/0006/0010/0012 在纯上游代码里的函数锚点改名/移除了，**全量变体（build.sh）在 0.2.17 上暂不可用**，需按 patches/README.md 手工重放后才能构建；局域网放行变体不受影响。

上游 0.2.17 相对 0.2.16 的要点（面向使用者）：**route tail skip 默认关闭**——Expert settings 里的「Skip rarely used parts of the model」（`STRATA_ROUTE_TAIL_SKIP`）此前在 NVIDIA 与 Radeon RX 9000 上默认开启，因质量损失报告改为默认关闭，想要速度的用户可在专家设置手动打开；**模型装不进内存的电脑上调低内存余量**——Setup 现在预留 17 GB RAM 空闲（原 24 GB），64 GB 内存的机器现在可装 47 GiB 专家层（原 40 GiB）；Coder 模型新 pinned build（官方 #3445）；单张 ≤16 GB 的 RTX 50 系 NVIDIA 卡默认多开一个速度设置（可关）；Control 与引擎继续同号 0.1.63。
