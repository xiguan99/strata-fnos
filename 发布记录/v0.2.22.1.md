# v0.2.22.1（2026-11-26）

应用版本 0.2.22.1（原版直通变体），对齐上游 Strata v0.2.22：host 0.2.22、control 0.1.69、CUDA 引擎 0.1.69。

## 本版变化

**不再自打增量补丁，树内容＝官方 AppImage 解包 + 官方引擎包，一个字不改。**

- 上游 v0.2.22（#7130）重写了主机接口的来源校验：`host/server/index.mjs` 里旧的 `isLocalOrigin` 白名单已删除，改由新文件 `host/server/request-guard.mjs` 统一把关。`/api` 请求的 `Origin` 与 `Host` 头同源即视为本站请求；跨站、以及别的本机端口一律 403；改动设置的 `/api` 还要求页面注入的 `x-strata-token`。
- 本包宿主原生绑 `0.0.0.0`，此时上游跳过 Host 头校验，浏览器同源请求直接放行 —— 局域网直连（`http://<NAS 地址>:8791/`）因此天然可用，**0004 局域网 Origin 补丁自本版退役**，不再重放。
- 变体守卫同步改写：构建脚本断言「守卫在位 / index.mjs 已接守卫 / 无 0004 残留 / 宿主绑 0.0.0.0 / 引擎随包」；冒烟新增「真启宿主实测来源校验」。

## 上游 v0.2.22 要点

- Inkling 2 Mini 双卡层切分的一个错误修复。
- 新增 `STRATA_SPLIT_LEND_RESERVE=0` 开关：双卡层切分时优先把专家放进更快的卡（默认为 0 时不改变现有行为）。
- 主机接口来源校验重写（见上）。自建域名访问需把域名写进 `STRATA_ALLOWED_HOSTS`；从反向代理地址打开会被当作跨站而拒绝，请用 NAS 自身的 IP/主机名。
- 升级后不再需要重启 Strata。
- `/v1/responses` 的长工具调用每 10 秒发一次 keep-alive，避免客户端读超时。

## 安装

应用中心「手动安装」选择该 fpk。已装旧版时应用中心会先卸载再装（`/vol1/@appdata/strata` 数据默认保留，模型与设置不丢）。

装好后注意两点：①若 8791 端口已被别的程序占用，宿主不会自动拉起（安装回调照常成功，日志写明占用者）；②首次加载模型会把随包引擎搬进引擎库，属正常行为，之后加载不再搬。
