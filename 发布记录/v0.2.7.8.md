# strata 0.2.7.8（2026-10-30）

## 修的是什么

用户报「网页角色界面里把第二张 2080 Ti 设成 Helper，加载出来仍全在一张卡上」。

根因是前端两条逻辑叠加，不是引擎不支持双卡（同一张表直接走 API 加载，双卡 layer split 正常起）：

1. 用户的选择正好等于「推荐」时，页面把角色状态清成 `null`（原设计：null = 用推荐）；
2. 但取有效角色时 `null` 先回落到「已加载实例的角色」（单卡 `{0:off,1:main}`），推荐排在它后面；
   加载请求在 `roles` 为 `null` 时又只发「推荐卡列表」+`gpusFromRecommendation`，服务端视其为
   「不是人选的」而忽略，最终仍按上次运行的角色起单卡。

改法：`roles` 为空就用推荐；`roleCards>1` 时**一律发 `gpuRoles`**；服务端在屏幕选角色那条路径
补一行角色日志（原来只有「从上次运行恢复」会打）。详见 `patches/0008-ui-roles-recommendation.md`。

## 运行参数

未变：`--max-context 262144`、`--kv-resident 16384`、`--vram-reserve-mib 512`、`--batch 2`、
角色表 `{"0":"off","1":"main"}`（单卡基线）；双卡为 `{"0":"off","1":"main","2":"helper"}`。
