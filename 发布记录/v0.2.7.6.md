## 仓库约定
- **引擎二进制永久不入 git**：`fnpack/app/engine-bundle/` 下单个文件就有几百 MB（`libcublasLt.so.12` 749MB、`strata` 479MB），一次 `git add -A` 会暂存 684MB，push 必然 408、仓库被撑成 GB 级。这些文件只随 fpk 与 GitHub Release 资产发布，仓库里保留元数据（`BUILD.json`/`SYSTEM-LIBS.txt`/`engine-component.json`）与忽略规则。

## 更正（2026-10-30，实测）
- **`--kv-resident` 引擎下限是 20480**（`strata --help` 原文：`keep N cells of each QSA layer in VRAM (min 20480)`）。0.2.7.5 验收记录里写的「`--kv-resident 16384` 生效」不成立——实际被引擎静默夹到 20480。
- 由此得出的核对口径：`args_written` 里写什么不等于引擎实际用什么，**必须读运行实例的 args + 引擎启动行**才能确认参数真的生效。
- **`--vram-elastic` 与 layer split 互斥**：开 layer split 时引擎日志直接打印 `--vram-elastic is off: a layer split has a cache per GPU`，不要以为弹性显存生效了。
